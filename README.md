# Работа с оптимизацией

## Реализовано: 
1. Получение списка и детальных страниц категории с сервера.
2. Добавлена динамическая подгрузка данных приложения с помощью Lazy loading и Suspense.
3. Добавлена подгрузка списка данных категорий с сервера с помощью Infinity Scroll.
4. Добавлена обработка ошибок с помощью ErrorBoundary.
